# Мини FTPS Server/Client

> [English version](README.md)

> [China version](README_CN.md)

Самодостаточный мини-проект FTPS-сервер/клиент (FTP over TLS/SSL) на языке C/CPP, построенный на библиотеке **crypery** (TLS 1.2/1.3). Сервер поддерживает аутентификацию, пассивный режим, шифрование каналов передачи данных и конфигурацию через JSON-файл.

## Особенности проекта

- **Собственная TLS-реализация** - не требует внешних криптобиблиотек (OpenSSL, GnuTLS и т.д.)
- **Поддержка TLS 1.2 и TLS 1.3** - автоматическое определение версии или принудительное указание
- **Конфигурация через JSON** - все параметры сервера задаются в файле `config.json`
- **Пассивный режим (PASV/EPSV)** - диапазон пассивных портов для передачи данных
- **Аутентификация по логину и паролю** - настраиваемые учётные данные
- **Шифрование control и data каналов** - PROT P (Private) и PROT C (Clear)
- **Полный набор FTP-команд** - LIST, MLSD, RETR, STOR, MKD, RMD, DELE, RNFR/RNTO, CWD, CDUP, PWD, SIZE и др.
- **Sandbox путей** - защита от выхода за пределы корневого каталога через `..`
- **Кроссплатформенность** - поддержка Windows (MSVC/GCC) и Linux/Unix
- **Самозначенный сертификат** - автоматическая генерация при отсутствии `localhost.crt`/`localhost.key`

## Параметры конфигурации

Конфигурация загружается из файла `config.json`. Все параметры имеют значения по умолчанию.

```json
{
    "port": 2121,
    "root": "ftps_root",
    "passive_port_start": 50000,
    "passive_port_end": 50100,
    "control_timeout": 60,
    "data_timeout": 30,
    "pasv_timeout": 10,
    "username": "ftpuser",
    "password": "ftppass",
    "cert_file": "localhost.crt",
    "key_file": "localhost.key",
    "use_tls": true,
    "tls_version": 0,
    "log_output": 0
}
```

### Описание параметров

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `port` | число | 2121 | Порт, на котором сервер будет слушать входящие FTP-соединения (1-65535) |
| `root` | строка | "ftps_root" | Корневой каталог FTPS-сервера. Все пути клиентов относительны этого каталога |
| `passive_port_start` | число | 50000 | Начальный порт диапазона пассивных соединений для передачи данных |
| `passive_port_end` | число | 50100 | Конечный порт диапазона пассивных соединений (не включительно). Сервер циклически распределяет порты в этом диапазоне |
| `control_timeout` | число | 60 | Таймаут (секунды) для control-соединения. После этого неактивного соединения будут разорваны |
| `data_timeout` | число | 30 | Таймаут (секунды) для data-соединения во время передачи файлов |
| `pasv_timeout` | число | 10 | Таймаут (секунды) для установки пассивного data-соединения. Клиент должен подключиться к пассивному порту в течение этого времени |
| `username` | строка | "ftpuser" | Имя пользователя для аутентификации на FTPS-сервере |
| `password` | строка | "ftppass" | Пароль для аутентификации на FTPS-сервере |
| `cert_file` | строка | "localhost.crt" | Имя файла сертификата сервера (PEM формат) |
| `key_file` | строка | "localhost.key" | Имя файла закрытого ключа сервера (PEM формат) |
| `use_tls` | булево | true | Включить/выключить TLS-шифрование. При `false` сервер работает в обычном FTP-режиме без шифрования |
| `tls_version` | число | 0 | Версия TLS: `0` (автоматически), `1` (принудительно TLS 1.2), `2` (принудительно TLS 1.3) |
| `log_output` | число | 0 | Вывод логов: `0` (и консоль, и файл), `1` (только консоль), `2` (только файл ftps_server.log) |

## Логирование

Сервер поддерживает логирование событий в консоль и/или в файл `ftps_server.log`.

### Параметры логирования

- Логи записываются с временными метками в формате `[YYYY-MM-DD HH:MM:SS]`
- Цифровые уровни логов: `0` (DEBUG), `1` (INFO), `2` (WARN), `3` (ERROR)
- Параметр `log_output` в конфиге: `0` (both), `1` (console), `2` (file)
- Файл лога `ftps_server.log` создаётся в текущей рабочей директории
- До инициализации системы логирования сообщения выводятся в stdout/stderr

## Командная строка

```
ftps_server.exe [config_path] [root_override]
```

| Аргумент | Описание |
|----------|----------|
| `config_path` | Путь к файлу конфигурации JSON. Если число - интерпретируется как порт (переопределяет `port` из config.json) |
| `root_override` | Переопределение корневого каталога из config.json |

Примеры:
```bash
ftps_server.exe                        # Использовать config.json по умолчанию
ftps_server.exe my_config.json         # Использовать свой файл конфигурации
ftps_server.exe 21                     # Использовать порт 21, конфиг по умолчанию
ftps_server.exe 21 /var/ftp            # Порт 21, корень /var/ftp
```

## Сборка

```batch
build_ftps.bat
```

## Использование сертификатов

Сервер пытается загрузить сертификат и ключ из файлов `localhost.crt` и `localhost.key` (формат PEM). Если файлы не найдены или некорректны, сервер автоматически генерирует самозначенный сертификат.

Для создания собственных сертификатов:

```bash
openssl req -x509 -newkey rsa:2048 -keyout localhost.key -out localhost.crt -days 365 -nodes -subj "/CN=ftps server"
```

## Поддерживаемые FTP-команды

| Команда | Описание |
|---------|----------|
| `LIST`, `MLSD` | Список файлов в каталоге |
| `RETR` | Получить файл (download) |
| `STOR` | Загрузить файл (upload) |
| `MKD` | Создать каталог |
| `RMD` | Удалить каталог |
| `DELE` | Удалить файл |
| `RNFR` / `RNTO` | Переименовать/переместить |
| `CWD` / `CDUP` | Сменить/вернуться в родительский каталог |
| `PWD` | Текущий каталог |
| `SIZE` | Размер файла |
| `PASV` / `EPSV` | Пассивный режим |
| `TYPE` | Тип передачи (A/I) |
| `PROT` | Уровень защиты (C/P) |
| `PBSZ` | Размер буфера защиты |
| `AUTH TLS` | Начать TLS-рукопожатие |
| `FEAT` | Поддерживаемые возможности |
| `OPTS` | Настройки команд |
| `SYST` | Информация о системе |
| `NOOP` | Проверка связи |
| `QUIT` | Завершить соединение |
| `REST` | Рестарт передачи |
| `MLST` | Метаданные файла/каталога |
| `SITE CHMOD` | Изменить права файла |
